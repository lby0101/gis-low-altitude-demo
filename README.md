# GIS低空全栈实战源码仓库

> 公众号：GIS开发手记  
> 专注方向：Cesium / ThreeJS / OpenLayers / Leaflet / Mapbox / PostGIS  
> 行业垂直：低空经济 · 无人机 · 空域仿真 · 实景三维 · 数字孪生大屏  

本仓库为 **公众号专属配套源码合集**，持续更新可直接落地、可开箱运行、无删减、无套路的 WebGIS 实战 Demo。

所有代码均为项目工程化级别，适合学习、二次开发、政企低空项目落地参考。

## 仓库定位
市面上大多教程只讲原理、不给完整代码。  
本仓库主打 **全套可运行源码 + 真实低空业务场景**，覆盖：

- ✅ Cesium 三维低空仿真、空域管理、航线回放、模型优化
- ✅ ThreeJS 三维模型融合、自定义场景开发
- ✅ OpenLayers / Leaflet / Mapbox 二维地图开发
- ✅ 二三维联动一体化解决方案
- ✅ PostGIS 三维空间分析、空域冲突、缓冲区、轨迹大数据处理
- ✅ 低空可视化大屏、性能优化、工程化避坑方案

## 目录结构

├── 01-Cesium-Demo # Cesium 低空三维实战案例
├── 02-OpenLayers-Leaflet # OpenLayers / Leaflet 二维地图 & 二三维联动
├── 03-Mapbox # Mapbox 可视化案例
├── 04-PostGIS-SQL # 低空空间分析 SQL 脚本合集
├── 05-ThreeJS-Demo # ThreeJS 三维自定义开发
├── common # 通用工具、公共组件、全局配置
└── docs # 开发文档、踩坑总结
